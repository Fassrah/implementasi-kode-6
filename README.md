# Attributing direct drivers to deforestation alerts with satellite imagery and AI

Studi Kasus: Kita akan mensimulasikan jaringan CNN menggunakan TensorFlow. Mengacu pada pemaparan Dr. Bart, CNN menerima input berupa "stacking" citra satelit Sentinel-1 dan Sentinel-2. Di simulasi ini, input tidak hanya 3 saluran warna (RGB), melainkan 6 saluran (mensimulasikan gabungan band optik dan radar) untuk menebak 3 kelas (Pertanian, Tambang, atau Bencana Alam).
